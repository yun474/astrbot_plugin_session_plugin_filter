# 会话规则

AstrBot 原生「自定义规则」的完整替代：按会话管理**插件权限**，以及**会话开关、LLM/TTS 开关、人格、模型、知识库**，带可视化配置面板。

原生自定义规则只能一个会话一个会话地配。想让某个群只能用几个插件，得把其他插件挨个点掉；想给几十个群统一换人格，得一个个改。这个插件的一条规则可以管任意多个会话，支持通配符和排除。

## 一条规则 = 一组会话 + 插件权限 + 会话设置

### 插件权限

- **只允许勾选的插件**（白名单）：这些会话里只有勾选的插件能用，其余全部失效，新装的插件默认也被挡在外面
- **禁用勾选的插件**（黑名单）：这些会话里勾选的插件被禁用，其余照常；一个都不勾就是不限制插件
- **专属**：插件旁边点「专属」，这个插件就只能在这些会话里用，其他所有会话都用不了

### 会话设置

每一项默认都是「默认」，表示不改动、沿用 AstrBot 自己的配置，只有改过的项才生效：

| 设置 | 说明 |
| --- | --- |
| 会话 | 关闭后 Bot 在这些会话里完全不响应 |
| LLM 回复 | 关闭后不再调用大模型聊天，插件指令照常可用 |
| 语音合成 | 关闭后回复不再转成语音 |
| 人格 | 强制使用某个人格，或者不使用人格 |
| 对话 / 语音识别 / 语音合成模型 | 强制使用指定的模型提供商 |
| 知识库 | 不使用知识库，或者指定知识库和检索条数 |

### 举个例子

想让「游戏群」只能用 3 个插件，「抽卡」插件只给游戏群用，并且游戏群用专门的人格和游戏攻略知识库：

1. 新建规则，会话里添加游戏群
2. 「插件」页：选「只允许勾选的插件」，勾上这 3 个插件，在「抽卡」那一行点「专属」
3. 「会话设置」页：人格选游戏群的人格，知识库选「指定知识库」并勾上游戏攻略

编辑器顶部会用一句话描述这条规则的效果，配完看一眼就知道对不对。

## 多条规则怎么算

- **插件权限叠加生效**：插件要被命中的每一条规则都放行才能用；同一个插件被多条规则设为专属时，在这些规则的会话里都能用
- **会话设置取最具体的**：精确写出的会话优先于通配符，同级时规则列表里靠前的优先，可以在编辑器底部上移/下移。比如「所有群关闭 LLM」再加一条「群 A 开启 LLM」，群 A 就是开启的
- 没有规则影响的会话，一切照常
- 系统内置插件永远不受影响

## 会话写法

- 在面板里按群名或会话 ID 搜索添加；会话 ID 也可以在聊天里发 `/sid` 拿到
- 通配符：`*` 匹配任意字符，`?` 匹配单个字符，例如 `*:GroupMessage:*` 是所有群聊
- 排除：在前面加 `!`，例如先加「所有群聊」，再加 `!aiocqhttp:GroupMessage:123456`，就是除了这个群以外的所有群

## 其他功能

- **严格模式**（默认开）：除了指令和消息监听，还会一起屏蔽被拦插件的事件钩子（LLM 请求前后、发送前装饰等）和 LLM 函数工具
- **静默拦截**：被屏蔽插件的指令直接吞掉，不会掉进 LLM 闲聊里
- **指令冲突分流**：两个插件注册了同名指令时，可以让 A 群用插件 A、B 群用插件 B，互不干扰
- **命中测试**：输入会话 ID，列出这个会话里哪些插件能用、被拦的插件被哪条规则拦了、每项设置来自哪条规则

## 从原生自定义规则迁移

面板底部有迁移卡片，按顺序点就行：

1. **导入原生规则**：把原生自定义规则里的插件禁用、会话开关、人格、模型、知识库转成规则，内容相同的会话会合并成一条
2. 检查导入的规则，没问题就保存
3. **清除原生规则**：删掉原生自定义规则，避免两边重复生效。会话备注名会保留

注意：原生的「模型」规则和用户在聊天里用 `/provider` 切换模型存在同一个地方，导入时会一起变成规则，规则里的模型会固定下来，用户再切换也不会生效。不想固定的话，导入后把那条规则的模型改回「默认」。

## 聊天指令

仅管理员可用，本插件自己的指令不受任何规则限制，不会把自己锁在外面。

| 指令 | 说明 |
| --- | --- |
| `/pf status` | 查看当前会话命中的规则、可用插件和生效的会话设置 |
| `/pf bind <规则名>` | 把当前会话加入指定规则 |
| `/pf unbind` | 把当前会话从所有规则里移除（通配符规则不受影响） |

## 实现方式

- **插件权限**：包装 AstrBot 内部的 `SessionPluginManager.filter_handlers_by_session`，原生的插件禁用配置仍然会先生效
- **会话设置**：AstrBot 运行时统一通过 SharedPreferences 读取原生会话规则，本插件包装这个读取入口，把规则里的设置叠加到原生值上。原生存储本身不会被修改，停用或卸载插件后自动还原

## 已知限制

- 装了本插件后，请不要再用原生「自定义规则」页面的批量修改。那个功能会先读出配置再写回，可能把本插件的设置写进原生存储
- 被屏蔽插件里带权限限制的指令，非管理员触发时仍可能收到 AstrBot 的「权限不足」提示，因为 AstrBot 在会话过滤之前就做了权限判断。可以在平台设置里关闭「无权限回复」规避
- 指令冲突分流的前提是两个同名指令在 AstrBot 的「指令管理」里都处于启用状态，在那里被禁用的指令是全局禁用的，本插件无法恢复
- 会话备注名还是在原生页面或 WebUI 的会话列表里改

## 数据

规则保存在 `data/plugin_data/astrbot_plugin_session_plugin_filter/rules.json`，可以直接备份。

## 兼容性

AstrBot >= 4.26
